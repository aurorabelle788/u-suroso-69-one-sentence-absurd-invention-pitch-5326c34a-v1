## The pitch

> The Lizard Roll, a toilet-paper holder that regrows a fresh roll like a lizard regrowing its tail the second the last sheet tears off.

The tiny everyday annoyance: the last sheet of toilet paper tearing off, leaving nothing but an empty cardboard tube at the worst possible moment. The ridiculous invention: a holder that simply regrows a fresh roll, the way a lizard regrows its tail — silly, yet weirdly plausible.

## What main.py does

`main.py` is a deterministic Python 3 program using only the standard library. It writes exactly one sentence — the pitch above — to `/output/entry.txt` (UTF-8, 134 characters, no trailing newline). It uses no network, reads no files outside the repository, and needs no environment secrets. Running it twice produces byte-identical output.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
